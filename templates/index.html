Week 2 Goal

Rough target for this lab: Build a Flask web app that takes the circuit parameters, computes the BJT DC bias ($V_B, V_E, V_C, V_{CE}, I_B, I_C, I_E$) for a common-emitter amplifier with voltage-divider bias, and displays the results.
